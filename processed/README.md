# Turkmen Legal Mixed Sources Dataset (Updated)

Этот набор данных содержит легально доступные текстовые корпуса и диалоги на туркменском языке, собранные, очищенные и подготовленные для обучения языковых моделей. Включает в себя данные из открытых источников и новости с сайта «Туркменпортал» с официального разрешения.

## Важное замечание о запрошенных объёмах
В публичном доступе **отсутствуют** открытые наборы из «тысяч книг» или «миллионов живых диалогов» на туркменском языке, которые можно было бы легально перераспространять. Любое массовое скачивание современных книг нарушает авторские права. 
Собранный архив содержит максимально возможный объём **законно доступных** данных, разделённых по лицензиям.

## Состав набора (336 076 записей, ~550 млн символов)

Набор разделён на две папки:

### 1. `monolingual/` (Монолингвальные тексты)
*   **hplt_tuk_cleaned.jsonl.zst** (150 282 записи)
    *   *Источник:* HPLT v2.0 (Common Crawl / Internet Archive).
    *   *Лицензия:* CC0 (для формата упаковки); тексты остаются собственностью авторов.
    *   *Очистка:* Строгая фильтрация через fastText (`lid.176`) для удаления не-туркменских веб-страниц.
*   **tkwiki_articles.jsonl.zst** (8 793 записи)
    *   *Источник:* Дамп туркменской Википедии.
    *   *Лицензия:* CC BY-SA 4.0.
    *   *Очистка:* Удалена вики-разметка, шаблоны, таблицы и технические страницы.
*   **turkmenspeech_transcripts.jsonl.zst** (107 235 записей)
    *   *Источник:* Транскрипции из TurkmenSpeech (Hugging Face).
    *   *Лицензия:* CC BY-NC 4.0 (Только для некоммерческого использования).
*   **tatoeba_tuk_sentences.jsonl.zst** (6 870 записей)
    *   *Источник:* Tatoeba Project.
    *   *Лицензия:* CC BY 2.0 FR / CC0.
*   **turkmenportal_news.jsonl.zst** (320 записей)
    *   *Источник:* Turkmenportal.com (новости).
    *   *Лицензия:* Официальное разрешение пользователя.
    *   *Очистка:* Извлечение текста, удаление HTML-разметки, дедупликация, проверка языка fastText.

### 2. `dialogues/` (Инструкции и диалоги)
*   **alpaca_turkmen_instruction_pairs.jsonl.zst** (40 699 записей)
    *   *Источник:* Машинный перевод набора Alpaca.
    *   *Лицензия:* CC BY-SA 4.0.
*   **kakugo_tuk_conversations.jsonl.zst** (21 877 записей)
    *   *Источник:* Синтетические и переведённые разговоры Kakugo-tuk.
    *   *Лицензия:* Apache-2.0.

## Формат файлов
Все файлы сжаты алгоритмом **Zstandard (`.zst`)** и содержат по одному JSON-объекту на строку (JSONL).
*   В монолингвальных файлах используется поле `"text"`.
*   В диалоговых файлах используется массив `"messages"` в формате `[{"role": "user", "content": "..."}, {"role": "assistant", "content": "..."}]`.

## Как использовать в Python
Для чтения файлов установите пакет `zstandard`:
```python
import json
import zstandard as zstd

dctx = zstd.ZstdDecompressor()
with open("processed/monolingual/tkwiki_articles.jsonl.zst", "rb") as f:
    with dctx.stream_reader(f) as reader:
        for line in reader:
            record = json.loads(line.decode("utf-8"))
            print(record["text"])
```

## Как расширять датасет
В корне архива находится скрипт `build_turkmen_dataset.py`, который был использован для скачивания, очистки и фильтрации этих данных. Вы можете модифицировать его для подключения дополнительных источников, если они появятся в открытом доступе. Также скрипт `process_turkmenportal.py` демонстрирует подход к сбору новостей с «Туркменпортала».
